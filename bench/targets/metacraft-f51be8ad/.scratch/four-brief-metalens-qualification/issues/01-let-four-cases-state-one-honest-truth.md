# 01 — Let four cases state one honest truth

**What to build:** Publish exactly four canonical metalens cases whose blind
briefs can test Adviser reasoning without leaking the immutable paper facts
used for reproduction and comparison.

**Blocked by:** None — can start immediately.

**Status:** resolved (2026-07-30)

- [ ] Exactly four canonical cases exist:
      `yun_2025_low_na_propagation`,
      `yang_2018_low_na_geometric`,
      `arbabi_2015_high_na_propagation`, and
      `khorasaninejad_2016_high_na_geometric`.
- [ ] Each case contains one immutable blind brief, one set of paper-locked
      facts, one comparison contract, and one fidelity classification.
- [ ] Adviser input contains only the blind brief and does not contain the
      hidden paper period, height, or lateral geometry.
- [ ] Advice comparison occurs only after advice is received and cannot
      rewrite the brief or paper facts.
- [ ] Cited geometry remains hidden post-advice fidelity and comparison truth,
      never a compiled constraint; the program derives period and height while
      generated lateral geometry retains only the dimension step stated by its
      blind brief.
- [ ] Yun selects the conventional full-2π comparator and explicitly excludes
      the 4π/3 optimized device.
- [ ] Yang selects one circular-polarization sublens and does not claim the
      complete Hartmann--Shack array.
- [ ] Arbabi is labeled HCTA-derived because the current brief does not
      represent the paper's complete single-mode-fiber incident field.
- [ ] Khorasaninejad selects only the 532 nm high-na device.
- [ ] Existing public example names that compete with these four canonical
      cases are retired without compatibility aliases.
- [ ] Case documents round-trip canonically and candidate input order cannot
      change their identities.
- [ ] Focused case, blind-advice, and architecture tests pass without running
      Adviser, Lumerical, or field propagation.
