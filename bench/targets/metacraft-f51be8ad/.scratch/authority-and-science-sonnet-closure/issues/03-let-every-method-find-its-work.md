# 03 — Let every method find its work

Type: implementation

Status: resolved (2026-07-29)

Blocked by: ticket 02.

## Outcome

Every method emitted by the scientific compiler has exactly one local
application operation. Missing implementation is an explicit fault, never an
empty advance that resembles an honest waiting study.

## Scope

1. Make the current scientific relationship and local operation set
   exhaustively comparable.
2. Keep method meaning in science and operation implementation in the local
   application.
3. Declare the common metalens proof tail once; retain propagation and
   geometric differences in their respective scientific modules.
4. Replace `operations.get(...); return ()` for unknown methods with one
   explicit internal fault.
5. Retain honest waiting behavior for missing advice, evidence, capability, or
   dispatch.

## Acceptance

- Every method name emitted by current relationships has one operation.
- No extra local operation can drift outside the compiled method vocabulary.
- An injected unknown method produces an explicit implementation fault.
- A scientifically waiting study still advances to no branch without fault.
- Propagation and geometric proofs keep their distinct response, phase, and
  evaluation operations.
- No public registry, graph, plugin, reflection, or workflow interface appears.
- Rust is unchanged.

## Focused tests

- compare the complete emitted method set with the local operation set;
- prove one unknown method faults;
- prove one honest waiting study remains waiting;
- compile both current metalens strategies and verify their shared tail and
  distinct scientific prefix.

## Do not add

Do not add a generic executor, dynamic discovery, decorator registry, public
operation table, or fallback method.
