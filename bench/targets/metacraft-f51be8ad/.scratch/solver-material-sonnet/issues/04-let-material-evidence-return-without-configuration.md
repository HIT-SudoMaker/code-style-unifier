return canonical live Ticket 10 to its human frontier without running it.

## Acceptance

  `brief → SolverMaterial → admission → sample → MaterialBinding → downstream evidence → result`.

  its admitted source-reference closure.
- Restart replay restores the same waiting study or result identity using only
  admitted objects.

  `materials/lumerical.toml`, read either environment file, call Adviser, open
  Lumerical, or execute Torch.

  atom/substrate pair. A material smoke requires one complete pair; a case
  sweep requires that case's complete pair.
- Architecture ratchets keep materials below application composition, science
  independent of Lumerical, and runtime imports acyclic.
- Ticket 10 names both material gates, links to this ticket, stays
  `ready-for-human`, and enables no live flag.
- Focused material, conduct, downstream-result, replay, and architecture tests
  pass.
- Pyright reports zero errors; touched production files have zero CSU hard
  violations; `git diff --check` is clean.

- Rust source and manifest remain unchanged.

## Stop and report

- Replay requires any configuration, external process, network call, or
  numerical execution.
- A fake result can close without retaining registration reachability.
- A live test or canonical sweep appears necessary to satisfy a local
  acceptance item.

## Do not add

  or full four-case delivery;
- a replay-specific compatibility path, registry, workflow framework, or
  second result model.
