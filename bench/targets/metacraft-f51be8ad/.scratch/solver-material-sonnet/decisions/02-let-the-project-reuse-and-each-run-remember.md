# Let the project reuse and each run remember

Label: `wayfinder:grilling`

Status: resolved (2026-07-30)

## Question

Which lifecycle owns solver-material registrations without creating a second
runtime authority or forcing every brief to repeat the same selection?

## Resolution

The project material library holds the reviewed current registrations under
Git. When a material-binding task is ready, the application admits only the
selected canonical solver-material documents into that run's Authority. Git
retains project history; the run retains the immutable snapshot that grounds
its sample, binding, result, and replay.
