## What to build

Verify the integrated movement without making semantic repairs. Create
`.scratch/harness-sonnet-hardening/closure.md` recording the exact changed-file
inventory, deletion inventory, retained-evidence before/after identity result,
test commands/counts/exclusions, static/architecture/source results, and scope
audit.

Run focused tests for every changed Interface, then the full deterministic
non-live suite, Pyright, the architecture suite, CSU, Markdown-link ratchet,
domain naming checks, and `git diff --check`, using only the repository Python
interpreter. Verify no Rust, Native, solver, benchmark, retained artifact,
`CONTEXT.md`, ADR 0021, map, or index change belongs to the implementation diff.

If any contract fails, reopen its owning Ticket 09-15; do not fix it in the
seal. Do not run the optional real campaign.

## Acceptance

- Every ticket's public behavior, stable fault, dependency, deletion, docs,
  and exclusion contract is satisfied with no compatibility road.
- Exact deterministic counts and all intentional deselections/skips are
  reported honestly; an excluded test is not called a pass.
- Pyright has zero findings and CSU has zero blocking findings attributable to
  the movement.
- Markdown links and diff whitespace pass.
- The final inventory contains only authorized implementation, tests,
  canonical prose, ratchets, planning-ticket lifecycle updates, and the closure
  record.
- No live usability, Native, scientific-performance, harness parity, or
  release-readiness claim is made.

## Exclusions

No semantic code/doc repair, real harness session, Native execution, retained
artifact rewrite, unrelated cleanup, commit, publication, map edit, or index
edit belongs in this ticket.
