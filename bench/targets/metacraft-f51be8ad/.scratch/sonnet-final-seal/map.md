# Map — Seal MetaCraft without widening it

**Label:** `wayfinder:map`

**Status:** destination reached (2026-07-29)

## Destination

One phase-final MetaCraft baseline in which:

- one execution record has one decoder;
- native product wording stops at the Lumerical Adapter;
- one private Python authority operation resolves current-revision contention;
- period and height advice derive one exact document reference;
- each propagation quantization returns either a phase set or an explicit
  refusal;
- Rust, the four authority verbs, scientific routes, physical policy, and
  canonical briefs remain unchanged.

After the four implementation tickets pass their focused gates, generated
work artifacts are removed through the owner-approved cleanup whitelist.
Canonical brief revision begins only in the next, separate design grill.

## Baseline

Local `main` at `eb696a5`.

The baseline already closes the large architecture:

```text
brief
  -> compile
  -> immutable Study
  -> conduct
  -> local composition
  -> qualified realization or Adapter
  -> observation
  -> scientific validation
  -> Rust Authority admission
  -> evidence
  -> Result
```

This effort seals residual implementation drift. It does not introduce a new
architecture.

## Accepted decisions

- All three Strong findings and all three Worth-exploring findings are in
  scope.
- Production Rust is frozen. No Rust source, protocol, storage, lifecycle,
  manifest, or binding changes are authorized.
- The public Rust Interface remains exactly
  `check -> view -> fetch -> decide`.
- Existing Authority history is never rewritten.
- New native session-open absence uses the stable reason
  `native_product_unavailable`; the original product exception remains only
  as an internal cause.
- `AvailableScience` retains one `advice` sequence. Period and height advice
  derive their exact reference from their canonical document only where
  metalens science requires it; ordinary `DesignAdvice` remains unbound and
  receives no synthetic reference.
- Authority admission records an advice identity. Scientific adoption remains
  the later `PeriodChoice` or `HeightChoice` basis.
- The checkpoint schema and advice projection remain unchanged. Newly emitted
  quantization refusals deliberately omit the redundant level suffix.
- Ordinary quantization refusal is a returned value, not a classified
  exception string.
- Verification stays local to each ticket. No complete suite, Rust scale
  diagnostic, native build, live adviser, live solver, or four-brief run is
  authorized.
- One ticket produces one commit after owner approval.
