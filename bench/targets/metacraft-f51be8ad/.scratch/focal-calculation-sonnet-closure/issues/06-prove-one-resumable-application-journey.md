## Outcome

Four application-level journeys prove that separate process invocations resume
one Authority-backed conduct life from brief through consultations and evidence
to stable terminal Results.

## Implementation

Build a test-only process driver around the real command Interface, canonical
brief/material inputs, one fresh application root, and recorded/fake external
evidence. It may launch the existing CLI repeatedly; it must not create a
production runner, mutable workflow, provider callback, or alternate state
store. Execute low-NA propagation, low-NA PB, high-NA propagation, and high-NA
PB. Terminate and restart between each consultation, after at least one
external-evidence pause, after retained native work, and before terminal replay.

At every invocation assert the byte-identical brief, one application root,
monotonic Authority revisions, exact current request, one accepted answer,
nonduplicated advice, permits, receipts and native attempts, exact binding
references, and ordered Run projection. Repeating without a new answer or
capability must reproduce the same consultation/WaitingStudies truth without
revision churn. Repeating after completion must return identical Result
references and must not open the evidence Adapter or call propagation.

## Acceptance

- All four recorded journeys reach `CompletedResults` in fresh subprocesses and
  reproduce identical scientific signatures on a second fresh root.
- Injected interruption after durable project/receipt/evidence boundaries does
  not duplicate native work or lose the frontier.
- Stale, duplicate and not-required answers leave Authority unchanged.
- `WaitingStudies` without an external-state change makes no progress and does
  not busy-loop.
- One propagation and one PB Native endpoint are documented as opt-in gates,
  spanning low/high NA across the pair; unavailable Native capability is an
  explicit incomplete gate, not a skip or pass. Terminal initiative closure
  requires both named endpoints to execute successfully.
- Pre-cutover application roots are exercised only as immutable stale-schema
  failures; every successful journey uses a fresh root and the current schema.
- Journey, command, Authority, Run, Result, Pyright, CSU and diff gates pass.

## Guardrails

Do not assert transcript wording, persist process sessions, read `runs/` as
recovery truth, or turn opt-in Native availability into a deterministic unit
test claim.
