## Role

This file is a non-normative navigation index. It owns neither architecture
nor ticket status.

- `CONTEXT.md` owns domain language.
- accepted ADRs own durable decisions and supersession.
- [spec.md](spec.md) owns this feature's implementation intent.

When this map disagrees with one of those owners, repair the map.

## Destination

Make the four metalens benchmark cases a trustworthy external proof of
MetaCraft judgment without making a paper the design truth. Paper facts,
brief-to-paper relations, comparison permission, and admitted Result measures
receive one owner each. The public benchmark schema changes once after four
private vertical slices are complete. One independent prefactor returns field
behavior to the existing field-execution Module. No general benchmark
framework, new workflow, Native run, or broad production rewrite belongs here.

## Expand-contract boundary

Tickets 02 through 05 form a private expansion. New-schema values remain
unexported and the old public catalogue stays green. This temporary internal
coexistence is not a supported compatibility contract.

Ticket 06 is the single public contraction. It exposes all four new cases and
deletes the old schemas, types, codecs, imports, fabricated representatives,
and forwarding paths in the same slice. No caller can observe a half-migrated
catalogue, and no release contains two public benchmark models.

## Fixed decisions

- The external seam remains stable case selection plus blind brief, canonical
  identity, and `MetalensBenchmarkCase.compare(...)`.
- Published reference owns paper truth; benchmark alignment owns the
  brief/reference relation; comparison contract alone owns permission; typed
  benchmark Result measures own restored MetaCraft observation.
- Facts use reported, derived, not-reported, and unresolved states. Absence is
  typed data, not an optional value convention.
- Alignment uses matched, adapted, independent, withheld, and excluded states.
  It owns no disposition, delta, or threshold.
- Comparison uses signed-difference, context, not-reported, and not-applicable
  rules. Every fixed-frame measure has one explicit rule and no default.
- Unresolved produces non-numeric context. Not-reported requires an actual
  not-reported fact. The two meanings never collapse.
- A comparable outcome requires both compatible numeric values and one finite
  MetaCraft-minus-reference difference.
- Result restoration is typed and exhaustive. Benchmark code does not inspect
  arbitrary objects, probe attributes, or try unrelated decoders.
- Yun's period is unresolved; aspect limits are Yun 10, Yang 8, Arbabi 8, and
  Khorasaninejad 8. They are supplied process inputs, not scans.
- The four papers remain four independent declarations under shared language.
  Similar evidence is not hidden by a cross-case builder.
- Referenced-body absence and malformed schemas are faults. Only explicit fact
  and rule values represent ordinary absence.
- Production never imports examples and receives no benchmark state.
- The only production ownership move transfers field realization restoration,
  direct-Debye construction, tensor storage crossing, and focal comparison from
  conduct to existing field execution.

## Delivery protocol

Implementation starts only after separate owner authorization. Work the
frontier and preserve the shared worktree:

1. one writer owns one approved ticket in a fresh context;
2. the root verifies its blockers, scope, and working-tree overlap first;
3. read-only review checks specification/ADR conformance and repository
   standards after the writer completes;
4. the root runs the ticket's focused deterministic gates before the next
   dependent ticket starts;
5. no ticket runs Live or Native work, and no seal ticket repairs semantics.

## Stop rule

The road closes when all eight tickets' acceptance statements are proved and
the final diff contains only the approved decision/canonical documentation,
external benchmark cutover, focused tests, one field-ownership move, and
closure records. "More Sonnet" alone is not a reopening condition. A new road
must name a concrete broken owner, Interface, dependency direction, state
transition, error contract, domain term, or verified scientific fact.

The deterministic road closed on 2026-08-07. The exact gate counts, marker
exclusions, four-case waiting inventory, and changed-file inventory are in the
[closure record](closure.md).
