# 02 — Let Yun prove the private benchmark contract

**What to build:** Establish the approved benchmark ownership decision and use
the Yun case to prove one complete, private new-schema path from reviewed source
facts and a blind brief through alignment, typed Result restoration, canonical
identity, comparison rules, and a fixed-frame comparison. The existing public
four-case catalogue must remain unchanged and green until the later contraction.

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] The accepted ownership decision is recorded in ADR 0020 and supersedes
      only ADR 0018's concrete benchmark-shape clauses; historical decisions are
      not rewritten.
- [x] The glossary and affected canonical documents define published reference,
      benchmark alignment, comparison contract, and benchmark Result measures
      without leaking implementation paths or paper-specific values.
- [x] The private new model gives paper truth, brief/reference relation,
      comparison permission, and typed MetaCraft observations exactly one owner
      each.
- [x] Published facts have closed reported, derived, not-reported, and unresolved
      states; legal state combinations do not depend on optional fields or prose.
- [x] Alignment has closed matched, adapted, independent, withheld, and excluded
      states and contains no comparison disposition or acceptance threshold.
- [x] Comparison has closed signed-difference, context, not-reported, and
      not-applicable rules, with exactly one explicit rule for every measure in
      the fixed ordered frame.
- [x] Typed benchmark Result measures define the complete fixed observation frame
      without arbitrary objects, dynamic attributes, free-form keys, or decoder
      probing.
- [x] A comparable output requires both compatible numeric values and a finite
      MetaCraft-minus-reference difference; an empty comparable output cannot be
      constructed.
- [x] Not-reported and unresolved meanings remain distinct: unresolved produces
      non-numeric context, while not-reported requires an actual not-reported
      fact.
- [x] The Yun blind brief uses aspect limit 10 as an independent process input
      and does not expose the paper period, height, geometry, efficiency, or phase
      result.
- [x] Yun's selected 800 nm-height comparator period is unresolved and carries
      no 400 nm or other fallback value.
- [x] The Yun reference, alignment, contract, canonical identity, strict
      restoration, wrong-case rejection, and low-NA propagation comparison are
      demonstrable through the new private case aggregate.
- [x] Any small Result fixture is explicitly a contract fixture and is never
      described as an exact Yun benchmark outcome.
- [x] Wrong caller types raise `TypeError`; malformed values raise stable-reason
      `ValueError`; missing referenced bodies and Authority faults propagate.
- [x] The new model remains unexported, has no compatibility alias or dual codec,
      and creates no supported second public benchmark Interface.
- [x] The old public catalogue and its existing tests remain green while this
      private tracer is reviewed.
- [x] No Native execution, solver-template change, or production benchmark
      dependency is introduced.

## Verification boundary

Verify the complete new behavior through the private Yun case aggregate and its
canonical comparison outcome, plus the unchanged existing public catalogue.
Tests must assert values and errors rather than private field order or module
layout. If the shared contract cannot support the remaining three current
Result families without changing its public meaning, this ticket is incomplete.

## Comments

- Reopened on 2026-08-07 by the Ticket 08 seal. `SignedDifferenceRule` did not
  yet declare or enforce its required benchmark alignments, and direct typed
  Result restoration used an assertion rather than the stable wrong-type
  `TypeError` contract. Current paper cases stayed green because none grants a
  signed difference, but the shared contract itself remained incomplete.
- Resolved again on 2026-08-07 after signed-difference rules acquired non-empty
  required matched subjects, comparison enforced those relations, and unsupported
  Result runtime types acquired the stable `TypeError` contract. The reopened
  benchmark and architecture gate passed 147 tests with zero type findings.
- Reopened by the final Spec review: public constructors still allowed some
  wrong runtime types to escape as `AttributeError`, the fixed Result frame did
  not reject arbitrary runtime objects at every constructor boundary, and a
  signed-difference rule did not yet prove its measure matched its fact key.
- Resolved after public value constructors restored the stable type/value error
  boundary, the Result frame rejected arbitrary runtime objects, and signed
  differences required identical measure and fact identities. The reopened
  contract, public-cutover, and Sonnet-ratchet gate passed 46 tests.
- Final review confirmed the boundary after comparison references and
  `measure_for` acquired explicit runtime guards. Their focused regressions pass
  within the final deterministic seal.
