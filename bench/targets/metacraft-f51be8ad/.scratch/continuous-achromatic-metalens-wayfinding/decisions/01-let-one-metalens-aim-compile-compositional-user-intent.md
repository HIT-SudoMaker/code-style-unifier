# Let one metalens aim compile compositional user intent

Status: resolved (2026-08-13)

Parent: [Find the continuous-achromatic metalens compilation road](../map.md)

Label: `wayfinder:grilling`

## Question

How should MetaCraft represent growing metalens varieties without turning
generic compilation into category dispatch, placing planning facts in a
Brief, or creating one Brief subtype per combination of target, spectrum, and
mechanism?

## Resolution

Keep one public `brief -> study -> result` lifecycle and let generic dispatch
select only the aim that owns the scientific language. The metalens aim owns
one compositional Brief whose orthogonal user facts include focal intent,
operating spectrum, illumination, material and fabrication constraints, and
an optional mechanism constraint. The current monochromatic cases become the
monochromatic value of that language; continuous-band focus becomes another
operating spectrum, not another aim, lifecycle, workflow, or control strategy.

Resolve a metalens Design before choosing a Relationship. The aim compiler
uses resolved intent and typed applicability to compile Method, Route, and
Proof. One applicable proof compiles, several unresolved applicable proofs
request consultation, and no applicable proof returns a typed refusal.
Cell-study sampling and work remain later bounded planning facts;
PeriodicResponse observations remain evidence; each Field remains
single-wavelength; one continuous-band conclusion aggregates exact admitted
facts without relabelling them.

Use one atomic schema cutover when implementation begins. Freeze the four
monochromatic Brief, Route, and Result witnesses first; do not retain a legacy
decoder, alias, fallback, or a parallel Brief lifecycle after replacement.
The publication proof must vary user facts and observe the compiled scientific
process, while every compiled Route must cite the intent, applicability, and
evidence that explain it in the reverse direction.

## Consequences

- `operating spectrum` and `mechanism constraint` are domain facts; category
  names and route names are not duplicate Brief fields.
- Continuous achromatism requires one physical aperture, a continuous band,
  fixed focal intent, design/holdout separation, wavelength-specific Fields
  and Focus facts, and a worst-case band conclusion.
- Holography, BIC, absorbers, FSS, new solver products, multifocal designs, and
  tunable designs do not shape this metalens decision.
