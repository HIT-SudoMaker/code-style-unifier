# 07 — Let metalens compilation and proof speak one language

**What to build:** One domain language from a metalens brief through design,
period and height choice, claim expansion, binding, and complete proof.

**Blocked by:** 06 — Let field and aim-neutral science name their behavior.

**Status:** resolved (2026-07-30)

- [ ] Brief, design, material, period, height, relationship, compilation,
      control-strategy, and proof names use the canonical domain vocabulary.
- [ ] Operations read in the established mental order `resolve -> prove ->
      bind -> close` without naming workflow positions or mutable status.
- [ ] Boolean values and predicates state their exact subject and polarity.
- [ ] Propagation-phase and geometric-phase proof language remains distinct
      where the physics is distinct.
- [ ] Period choice still precedes height, project materials still choose, and
      solvers still verify.
- [ ] Proof relationships, ready tasks, findings, refusals, advice identity,
      serialized documents, and canonical study bytes retain their meaning.
- [ ] Generic values acquire no metalens import and the runtime dependency
      graph remains acyclic.
- [ ] No compatibility aliases or duplicate old vocabulary remain.
- [ ] Compilation, standard-study, material, period, height, relationship,
      proof, architecture, and static type tests pass.
