# 04 — Let four canonical briefs live outside production

**What to build:** Four repository-owned example cases whose concrete briefs
and paper-comparison truth are external inputs to MetaCraft rather than values
embedded in the installable production package.

**Blocked by:** 03 — Let material binding return an honest outcome.

**Status:** resolved (2026-07-30)

- [ ] The reusable brief types remain in production science while all four
      concrete canonical briefs, paper facts, comparison contracts, case
      factories, and delivery selection live in the repository-root example
      layer.
- [ ] Production modules do not import the external example layer.
- [ ] The installable package exposes no examples subpackage, canonical case
      factory, or compatibility alias.
- [ ] Each relocated brief has exactly the same canonical bytes and content
      identity as before the move.
- [ ] Offline example inspection, named selection, stable four-case order, and
      serialization work without opening Authority, an adviser, a solver, or a
      workstation.
- [ ] Example and delivery tests import concrete cases only from the external
      example layer.
- [ ] Static type checking covers the external example entry points.
- [ ] A built-package smoke test proves that MetaCraft imports successfully
      without packaging the four concrete briefs.
- [ ] No brief wording, wavelength, numerical aperture, material family,
      control strategy, geometry intent, paper truth, or comparison meaning
      changes.
