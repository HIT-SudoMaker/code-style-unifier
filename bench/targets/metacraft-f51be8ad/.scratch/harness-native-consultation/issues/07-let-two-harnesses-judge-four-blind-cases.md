## Verification boundary

This is the only ticket authorized to run agent harnesses. Its eight
transcripts test usability and conservative judgment, not scientific evidence.
A missing local harness, failed skill discovery, invalid answer, or evidence
escalation is recorded honestly and does not become a fabricated pass.

## Acceptance outcome

Exactly eight fresh sessions were attempted once. All retained events pass the
corrected confinement audit. Two chained amendments preserve the original seal,
the first audit correction, and every old/new retained-artifact identity. The
second amendment removes raw and JSON-escaped machine paths, temporary-session
identifiers, and UUIDs from transcripts, stderr, audits, outcomes, and derived
reports, then re-audits the sanitized projection. Both amendments record zero
reruns. Codex could not execute the capsule-local installed command under its
workspace policy; Claude Code authentication expired before tool use.
Consequently all eight sessions remain at period consultation with no advice,
answer, period, or height. The two unchecked items above are intentionally unmet
usability/scientific criteria, not converted into a passing result.

Final Standards review made the audit fail closed for missing or unknown
top-level event types, malformed required fields, case-changed tool names, and
Codex file-change writes. Regression tests prove those shapes are rejected;
all retained transcripts continue to pass without amendment or rerun.
