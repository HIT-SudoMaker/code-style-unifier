# Map - Harness-native consultation

**Label:** `wayfinder:map`

**Status:** sealed (2026-08-09)

## Role

This is a non-normative navigation index. ADR 0021 owns the accepted
architecture, `CONTEXT.md` owns domain language, [spec.md](spec.md) owns
implementation intent, and each ticket header owns its status and blockers.

## Destination

Replace the embedded OpenAI-compatible client with one provider-free grounded
consultation Module, one resumable conduct life, one local command Adapter, and
one shared skill. Codex and Claude Code are the current acceptance targets.
Yun, Yang, Arbabi, and Khorasaninejad provide the closed-book scientific
matrix. Reasonix and Pi remain unverified future candidates.

## Dependency graph

```text

```

Tickets 01 and 02 are the initial frontier. Ticket 03 deliberately follows
period because height must contain the adopted period. Ticket 04 joins exact
brief restoration and both consultations into the sole conduct lifecycle.
Ticket 05 exposes that deep Interface through one thin command. Ticket 06 can
then delete the old road and publish the one skill without a dual supported
path. Ticket 07 performs the only harness sessions. Ticket 08 verifies but
does not repair semantics.

## Stop rule

The road closed after eight resolved tickets, no embedded provider path, one
shared skill, eight honest clean-session transcripts, and one green
deterministic seal. The sessions did not demonstrate harness usability; that
failure remains explicit in the closure record. No MCP server, future-harness
claim, or Native solve was added to make the feature appear more complete.
