# Let one conservative cell study begin every metalens design

Label: `wayfinder:map`

Status: resolved (2026-08-10)

## Destination

Reach one implementation-ready decision set for a provider-free metalens
recommendation seam that turns an incomplete brief into one physically
coherent, bounded, user-reviewable cell study plan for propagation or PB
phase, without claiming an optimum or weakening the later evidence boundary.

## Notes

- The six formerly open decisions are resolved on 2026-08-10 and are handed
  to the implementation specification below. Production changes remain
  ticket-scoped; solver execution and large benchmark runs remain out of
  scope.
- Preserve the canonical `brief -> study -> result` cadence and the accepted
  harness boundary in ADR 0021.
- Preserve ADR 0022: sampling bounds period legality; order regime changes the
  proof obligation rather than vetoing a sampling-legal period.
- Refine ADR 0011 openly if one coherent cell-study recommendation replaces
  separate period and height consultations; do not change its meaning
  silently.
- Use `research` for external physical facts, `grilling` and
  `domain-modeling` for human decisions, and `codebase-design` for the final
  Module and Interface boundary.
- Sonnet means common constraints first, route-specific forecasts second,
  exact study work third, and admitted response evidence last.

## Decisions so far

- [Let physics bound a conservative starting study](decisions/let-physics-bound-a-conservative-start.md) — Hard legality, route-specific forecasts, exact bounded coverage, and response evidence are separate; no universal solver-task cap is a physical law.
- [Let recommendation preserve user authority](decisions/let-recommendation-preserve-user-authority.md) — User facts and exact acceptance remain authoritative; a source-grounded harness may select only an existing option, while Authority retains truth and runs project a readable decision story.

## Implementation handoff

The implementation specification and eight vertical tickets live beside this
map in `spec.md` and `issues/01` through `issues/08`. They form one road:

`01 → 02 → 03 → 04 → [05, 06] → 07 → 08`.

Resolved decisions: focal geometry, bounded study extent, coherent harness
question, Authority/run projection, measured-response gates, and the
cell-planning Module cutover are recorded in `decisions/` and are part of this
single implementation road.

All eight implementation tickets are resolved. The final acceptance seam is
`tests/acceptance/test_four_case_cell_study.py`; the four briefs close through
the bounded card and deterministic `CellStudyPlan` without loading a solver.

## Out of scope

- Automatic global optimization or a claim that the recommended plan is the
  unique or best physical design.
- Paper-value equality as a production threshold or benchmark truth entering
  production recommendation grounds.
- Live Lumerical sweeps, aperture formation, field propagation, and focus
  calculation during this decision map.
- A generic metasurface planner, provider registry, model Adapter, plugin
  framework, or separate Codex and Claude Code implementations.
- Achromatic, resonant-geometric, microwave, holographic, quasi-BIC, and
  frequency-selective method implementation. The selected Interface may leave
  room for later typed mechanisms without pretending to implement them now.
