# Let recommendation preserve user authority

Label: `wayfinder:grilling`

Status: resolved (2026-08-09)

Assignee: `/root`

Map: [Let one conservative cell study begin every metalens design](../map.md)

Blocked by: [Let physics bound a conservative starting study](let-physics-bound-a-conservative-start.md)

## Question

What exact decision may MetaCraft recommend, which brief facts must remain
exclusively user-owned, what explanation must accompany the recommendation,
and at which point must the harness return control instead of choosing or
expanding on the user's behalf?

## Comments

### 2026-08-09

The owner confirmed that submitting an exact option identity may act as the
explicit acceptance of the user or their delegated harness; no third mutable
confirmation state is wanted. The owner also requires source-grounded harness
research when supplied local grounds cannot support a conservative choice,
and wants every accepted recommendation retained with the brief and later
run history.

The existing domain language creates one storage question that must remain
explicit before resolution: `application root` is the durable project
boundary, `authority/` owns scientific truth, and `runs/` owns product
artifacts. The proposed interpretation is therefore to retain brief, external
claims, advice, acceptance, and plan as Authority records while each run owns
a human-readable projection that cites those exact references. `runs/` must
not become a second source of scientific truth, and no parallel `WorkProject`
wrapper is introduced.

## Resolution

The user exclusively owns the requested wavelength, numerical aperture,
focal length, aim, performance objectives, declared materials and process
limits, explicit cell constraints, and execution extent. The current
metalens method fixes air-side focusing and a circular aperture; aperture
radius and later site count are deterministic derivations, not harness
recommendations. A different output medium or footprint requires a different
method decision rather than another optional field in the current Interface.

MetaCraft may recommend one existing conservative option containing an exact
period context, height, bounded lateral study, work count, forecast, caution,
and response obligation. A source-grounded harness should research primary
papers or official documentation when local grounds cannot distinguish the
surviving options. It may cite those sources, choose one exact option identity,
or return `evidence_required`; it may not create dimensions, constraints,
budgets, evidence, or a new option.

Submitting the exact option identity is the explicit acceptance of the user or
their delegated harness. No third confirmation state is introduced. No
bounded expansion is automatic: any later expansion must cite measured
response and return through its own accepted plan.

The existing `application root` remains the work-project boundary without a
new `WorkProject` type. Authority retains the exact brief, external claims,
advice, acceptance, plan, and evidence as durable truth. A run may carry a
human-readable manifest generated from those records, but the manifest is a
projection with exact references and cannot become a second scientific truth.
