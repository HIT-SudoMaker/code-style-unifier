# Let one bounded study replace the full grid

Label: `wayfinder:grilling`

Status: resolved (2026-08-10)

Map: [Let one conservative cell study begin every metalens design](../map.md)

Blocked by: [Let physics bound a conservative starting study](let-physics-bound-a-conservative-start.md)

## Resolution

The accepted plan owns an exact, deterministic, bounded work list. The extent
is a typed user-owned fact; it is never inferred from a workstation lane or a
free-text budget. Propagation plans contain one response work item per
selected geometry. PB plans contain one unrotated anisotropic geometry and
exactly two linear-input response items (`x`, `y`) per candidate. Orientation
is analytical after qualification and never creates solver work. Downstream
execution projects this list verbatim and must not recreate a one-dimensional
grid or a Cartesian product.

## Question

How should a selected starting plan state exact propagation or PB lateral
geometry candidates, response channels, and solver work count so that it
covers the physically relevant trade-offs without reconstructing an
unconditional one-dimensional or Cartesian fabrication sweep downstream?
