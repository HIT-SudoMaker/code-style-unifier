## Resolution

Cell planning emits one decision card containing complete immutable options:
period context, height, exact geometry identities, response channels, work
count, forecasts, cautions, and provenance. An external harness may select an
offered `option_id` or return `evidence_required`; it cannot edit dimensions,
constraints, criteria, or extent. Forecasts remain forecasts and never become
solver evidence merely because an option was selected.

## Question

What is the smallest consultation request and answer contract that lets an
ordinary Codex or Claude Code harness choose one conservative, physically
coherent cell study plan while keeping forecasts, cautions, external claims,
user facts, and future solver evidence visibly distinct?
