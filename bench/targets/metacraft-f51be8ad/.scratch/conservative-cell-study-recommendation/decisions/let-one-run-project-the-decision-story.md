# Let one run project the decision story

Label: `wayfinder:grilling`

Status: resolved (2026-08-10)

- [Let recommendation preserve user authority](let-recommendation-preserve-user-authority.md)

## Resolution

Authority remains the only source of scientific truth for the brief, material
binding, period choice, advice, accepted cell-study plan, expansions, and
response evidence. Each application-root run may write a deterministic,
human-readable manifest projection that cites those Authority references;
`runs/` is never read for recovery and no second `WorkProject` lifecycle is
introduced. An expansion is a new immutable accepted plan citing its parent
plan and measured response.

## Question

How should each application-root run project the exact brief, source-grounded
external claims, accepted advice, selected cell study plan, expansions,
response evidence, warnings, and user decisions without moving durable truth
out of Authority or inventing a second `WorkProject` lifecycle?
