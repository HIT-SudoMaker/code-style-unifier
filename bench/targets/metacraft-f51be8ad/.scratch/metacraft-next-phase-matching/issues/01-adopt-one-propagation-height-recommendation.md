# 01 — Adopt one propagation height recommendation

**What to build:** A researcher can compile the standard propagation study,
receive a provider-neutral expert recommendation over its finite height domain,
and obtain one traceable `HeightChoice` only when deterministic scientific
validation accepts that recommendation.

**Blocked by:** None — can start immediately.

**Status:** wontfix

**Superseded by:** [Metalens Sonnet convergence](../../metalens-sonnet-convergence/spec.md).

- [x] The standard visible propagation study derives the approved finite height
  domain without expanding it into an unconditional height-by-diameter sweep.
- [x] The compiled height domain records the exact route, brief, period,
  materials, aspect limit, fabrication grid, and allowed heights without
  claiming solver observations.
- [x] The adviser receives the exact brief and immutable height domain, and
  records provider, model, request, response, recommendation, and reasoning
  identities without provider branding in the public module name.
- [x] Advice cannot create work, invoke a solver, mutate a study, propose an
  authority transition, or satisfy a proof obligation by itself.
- [x] The selection policy accepts exactly one recommended height only when it
  is in the compiled domain and consistent with the exact propagation route
  and brief.
- [x] Unavailable, malformed, stale, or out-of-domain advice leaves
  height unresolved without rounding, substitution, or a silent default.
- [x] The `HeightChoice` record cites the brief by exact identity and cites its
  advice, domain, and route through exact references.
- [x] The compiled proof exposes no detailed lateral-sweep task until the exact
  `HeightChoice` evidence has been admitted.
- [x] The chosen height recomputes a non-empty propagation fabrication domain
  from the aspect limit and the 10 nm lateral grid.
- [x] Deterministic fixture advice remains visibly synthetic and cannot be
  presented as a native `HeightChoice` conclusion.
- [x] Identical exact inputs produce identical advice validation, selected
  height, fabrication bounds, and canonical identity.
