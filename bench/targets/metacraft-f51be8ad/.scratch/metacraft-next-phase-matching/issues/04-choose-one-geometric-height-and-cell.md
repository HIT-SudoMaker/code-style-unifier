# 04 — Choose one geometric height and cell

**What to build:** A researcher can use the same controlled recommendation
language with an independent geometric-phase evidence chain, fix one height,
gather a Jones library, and select one anisotropic cell for Pancharatnam–Berry
rotation.

**Blocked by:** 01 — Adopt one propagation height recommendation.

**Status:** wontfix

**Superseded by:** [Metalens Sonnet convergence](../../metalens-sonnet-convergence/spec.md).

- [x] The geometric route reuses the provider-neutral advice interface and
  deterministic validation rules without borrowing propagation observations,
  phase coverage, or `HeightChoice`.
- [x] A geometric height recommendation is accepted only when its exact domain,
  route, brief, materials, period, and fabrication constraints support it;
  otherwise height remains unresolved.
- [x] The chosen height recomputes the geometric fabrication domain from the
  aspect limit and 20 nm lateral grid before the detailed fin sweep begins.
- [x] The fixed-height Jones library rejects mixed heights and retains typed
  rectangular-fin length, width, height, material, and period with
  `length > width`.
- [x] Each candidate gathers x- and y-linear inputs sequentially under one
  permit and retains the complete linear Jones response and exact execution
  evidence.
- [x] The admitted polarization convention fixes handedness, propagation
  direction, time sign, basis order, viewing direction, and rotation sign.
- [x] Converted and retained circular coefficients, phases, and powers remain
  separate and traceable to the raw Jones evidence.
- [x] One cell is selected deterministically from useful conversion and retained
  leakage without inventing a hard optical threshold.
- [x] The selected cell cites its exact `HeightAdvice`, `HeightDomain`, Jones
  observations, convention, route, and binding.
- [x] Cell selection creates no orientation-specific FDTD task.
