# MetaCraft design

## Anchor

Keep the canonical brief byte-identical and resume its same application root.
Treat a pre-cutover root as immutable historical evidence; use a fresh
application root for the current schema. Clarify only an unresolved user fact,
and require confirmation before changing a declared fact. The anchor is complete
when the brief, reviewed material library, and one current root are identified.

## Conduct

From the installed root, run `.\metacraft.exe conduct --brief <brief>
--application-root <application-root> --material-library <material-library>`
with literal paths. Supply an explicit local execution environment only when
the user has made that capability available. Read the typed outcome; Authority
is lifecycle truth and `runs/` is not. The conduct step is complete when exactly
one typed outcome is observed.

## Consult

On `consultation_required`, use the exact request identity, grounds, legal
candidates, cautions, research mode, and answer contract. For `source_grounded`,
keep every consequential claim beside its traceable locator; for `closed_book`,
use only the request. Prefer one conservative legal recommendation citing the
decisive grounds. If those grounds cannot support one, return
`evidence_required`. Save one canonical answer for this request, repeat the same
command once with `--answer`, then stop at the next typed outcome. Consultation
is complete when that outcome is reported without changing the anchor.

## Resume

On `waiting_studies`, stop until a named external capability or evidence fact
has demonstrably changed. After that change, repeat the same command against the
same root and stop at its next typed outcome. Resume is complete when the changed
fact and the newly observed outcome are both reported; an unchanged wait remains
stopped.

## Stop

- On `completed_results`, stop and report the exact Result references.
- On `invalid_brief` or `unsupported_aim`, ask only for the unresolved user fact.
- On `evidence_required`, unavailable execution, or an unexpected fault, stop
  and report the exact next fact or capability.

Keep every choice inside the emitted contract: use its material and candidates,
submit an answer only for its current request, and let MetaCraft own FFT, CZT,
ASM, and VASM realization. Preserve rejected input and completed state exactly;
root substitution, silent repair, repeated unchanged waits, and inferred results
are invalid continuations.
