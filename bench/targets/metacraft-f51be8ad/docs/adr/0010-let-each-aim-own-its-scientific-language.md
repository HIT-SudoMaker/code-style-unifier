# 0010 — Let each aim own its scientific language

Status: accepted

MetaCraft keeps one public scientific lifecycle, `brief → study → result`, but
does not turn one aim's proof vocabulary into universal workflow stages.
`Field` remains reusable scientific language. `ApertureRegime`, `Aperture`,
`FocalRegion`, and `Focus` belong to the metalens focus objective; another aim
receives its own language only when a real proof is implemented.

A route is the content-addressed selection of claims and methods, not a dotted
control-strategy name. A proof identifies scientific meaning; a task binds
that meaning to exact inputs, prerequisite evidence, consultations, and one
realization when execution requires one; evidence answers that exact task.
Unimplemented aims and inapplicable methods return typed compilation refusals
instead of speculative proof graphs.

This decision supersedes the route-identity and future-proof-fixture clauses
of ADR 0002 and ADR 0004, and narrows ADR 0006's aperture-to-focus sequence to
the metalens focus objective. It changes no Rust authority state or protocol.
It is grounded in the
[scientific compilation dimensions](../research/2026-07-22-metasurface-scientific-compilation-dimensions.md)
and
[Field and Sonnet language audit](../research/2026-07-27-field-semantics-and-sonnet-language-audit.md).
