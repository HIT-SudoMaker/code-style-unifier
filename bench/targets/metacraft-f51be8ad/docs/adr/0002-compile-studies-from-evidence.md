# 0002 — Compile studies from evidence

Status: accepted

## Context

A fixed workflow cannot express how aim, band, control strategy, aperture regime, material constraints, solver capability, and available evidence alter a metasurface study.

## Decision

One pure Python compiler composes a typed study from a brief, optional AI advice, admitted evidence, registered claims and methods, and qualified capabilities. Compilation is deterministic at its pure seam. It emits only tasks whose prerequisites are satisfied and recompiles after new evidence is admitted.

A route is a compiled value that names one coherent claim–method proof topology. It is not an executor, a package-level workflow, or an end-to-end orchestration chain. Scientific modules declare terminal claims or contribute methods, evidence forms, pure transformations, and capability needs to the compiler.

The current low-na metalens proof supports propagation-phase and geometric-phase control methods. The geometric-phase method uses the Pancharatnam–Berry rotation mechanism. Both methods share one lifecycle, compiler, runner, aperture contract, and result closure while retaining the scientific evidence differences required by their mechanisms.

## Consequences

A configured LLM adviser can improve a design proposal but cannot select authority state. Adding providers, future aims, control strategies, aperture regimes, matching policies, or numerical methods extends Python's scientific modules, compiler rules, and evidence vocabulary, not the Rust protocol.

No route may introduce a second lifecycle or require callers to hand-assemble an end-to-end workflow. The route-neutral runner executes only ready tasks from the compiled study.
