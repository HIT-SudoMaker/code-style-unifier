# Decision traceability

Use the shortest durable chain that preserves meaning:

`research record → ADR → current spec → ticket → test`

- Research records live in `docs/research/` and establish external facts.
- Accepted system boundaries live in `docs/adr/`.
- Current product intent and tickets live under one feature in `.scratch/`.
- Tests are the implementation evidence.

Canonical design is in `DESIGN.md`, `AUTHORITY.md`, `SCIENCE.md`, `DEVELOPMENT.md`, `ROADMAP.md`, and `CONTEXT.md`. Historical sequence and activation documents are not authority.
