# Test correction-action identifiability

## Question

reference-on observations identify a useful delivered correction action,
abstention, or need for another probe without aberration-truth access or full
wavefront recovery?

## Kill rule

If useful actions cannot be distinguished within the declared observation
ceiling, stop active-policy development and retain only the supported fixed or
classical strategy.
