# Choose the first native coherent-microscopy demonstration

## Question

Which coherent microscopy modality, specimen class, aberration regime, pupil
geometry, and independent raw-science endpoint will define the first native
demonstration, and which corrections are physically safe to apply?

## Decision boundary

The choice must preserve the reference-assisted coherent observation model and
must be representative enough to expose SLM calibration, spatial-bandwidth,
and field-transfer limitations. A fluorescence experiment requires a different
forward model and is not an interchangeable first demonstration.
