# Write the canonical restoration research prompt

## Question

What single prompt will reliably produce a source-grounded historical review,
competitive analysis, falsifiable novelty claim, and implementation-shaping
research report without prematurely asking for code?

## Resolution

The canonical prompt is
[`restoration-research-prompt.md`](../../prompts/restoration-research-prompt.md).
It must be uploaded together with
[`Restoration Foundations`](../../research/restoration-foundations.md).

The prompt freezes the candidate hardware and causal contract, requires an
atomic adversarial audit of the companion brief, and ends in a
`Continue / Narrow / Kill` verdict before implementation architecture is
reopened.

GPT Pro returned `Narrow`. The result authorizes bounded feasibility work, not
a broad Adaptive Restoration implementation. The local analysis and returned
audit are consolidated in
[`Restoration Research Design`](../../restoration-research-design.md).
