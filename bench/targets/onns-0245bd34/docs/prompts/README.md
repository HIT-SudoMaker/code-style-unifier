# Project Prompts

The canonical restoration research prompt is
[`restoration-research-prompt.md`](restoration-research-prompt.md).

Upload it together with
[`Restoration Foundations`](../research/restoration-foundations.md). The
companion brief supplies the formulas, reproduced implementation excerpts,
evidence boundaries, frozen candidate contract, and local provisional
conclusions that GPT Pro must independently audit.

The prompt requires:

1. a staged multi-source search and deduplicated evidence table;
2. exact-neighbor and adjacent-prior competition searches;
3. formula, identifiability, hardware, causality, and matched-budget audits;
4. an atomic `Agree / Qualify / Reject` review of the companion brief;
5. ranked kill tests and an explicit `Continue / Narrow / Kill` verdict.

It asks for research, not code generation. Superseded prompts have been
deleted so they cannot silently steer new work.
