# SSRHM Conic and sampled Wave Source deepening

**Status:** Accepted — implemented present truth

**Directional-inventory supersession:** this behaviour-preserving decision
froze the then-current pre-directional thirty-action inventory. That historical
count is superseded by the later directional cutover. Current truth is
twenty-four Optical Component actions plus separate public inventories of
three state-only directional owners, three closed Terminal/diagonal enums, and
two Assembly-issued Encounter reference types. The Conic and sampled-Source
decisions below remain authoritative.

ChromatixNext deepens two existing private seams without changing optical
capability or public behaviour. The implemented structure has two logically
ordered phases: first the Certified Conic Encounter, then Sampled Wave Source
Synthesis. Each phase has its own acceptance barrier so numerical-proof risk
cannot be mixed with Source-lifecycle risk.

The decision prescribed strictly serial execution, but the execution history
contains one disclosed deviation: an authorized sampled-Wave candidate began
before the Conic acceptance barrier closed. That candidate was excluded from
the Conic manifest and later received independent Source qualification, so the
scientific result and phase attribution remain bounded. The elapsed process
cannot be rewritten as strictly conforming; final process sealing therefore
requires an explicit one-time maintainer waiver and must preserve this record.

## One-time maintainer waiver

On 2026-08-14, the maintainer explicitly accepted the disclosed execution-
order deviation while authorizing final scientific-foundation closure. This
waiver satisfies the process-sealing condition above exactly once. It covers
only the fact that the sampled-Wave candidate began before the Conic acceptance
barrier closed; it does not waive either phase's independent qualification,
manifest identity, scientific contract, public Interface, state or failure
contract, device evidence, or final gate. It is not precedent for overlapping
future acceptance barriers.

This decision does not reverse ADR-0008's rejection of splitting Conic
Numerical Support merely because it is long. ADR-0014 authorizes a different
change for measured reasons: the existing Implementation contains distinct
geometry, continuous-root, certified-polynomial, host-proof-bridge, and
device-refinement change domains, together with string-keyed fact clusters.
It also closes, as a new initiative, the Conic internal-fact redesign that the
ADR-0013 correction deliberately deferred rather than rejected.

The Certified Conic Encounter keeps `conic_encounter` as its sole numerical
Interface and keeps the Conic Even Asphere Surface as the passive public-facing
adapter. Its private Implementation is organized around named local
geometry, the base-conic continuous solver, and the polynomial certified
solver. The polynomial path continues to converge through device exclusion,
the existing exact Fraction/Sturm certification owner, and device-local
differentiable refinement. Immutable named facts replace string-keyed geometry
and staging payloads. No public solver, solver selector, general polynomial
framework, second encounter path, or new host-computed continuous result is
admitted.

Sampled Wave Source Synthesis gives Plane Wave, Gaussian Beam Source, and Point
Source one private mechanical owner for their shared validation,
normalization dispatch, single-slot envelope caching, fixed-double output
construction, and Source Lineage preservation. The design-it-twice tracer
showed that composition required a broad callback protocol or displaced the
registered cache from its physical Source owner. After the required explicit
maintainer approval, the implementation therefore selected a restricted
private `_SampledWaveSource` base. It is not a public inheritance family and
does not replace the generic private Source lifecycle owner. Each Source
continues to own its equation, authored parameters, sampling rejection,
power-normalization kernel, cache-key physical facts, and stable error
identities. A universal Component or Source framework remains forbidden.

Both phases are behaviour-preserving architecture work. At their acceptance
boundary, public exports, the then-current pre-directional action inventory,
equations, floating-point operation order, tolerances,
root selection, outputs, gradients, fixed-double admission, CPU/CUDA/Meta
behaviour, Parameter and Buffer identities, state keys, cache invalidation,
Source Lineage, failure identities, finding order, Assembly replay, and
Workstation execution are frozen. A proposed change that requires any of these
facts to move must stop and become a separate scientific decision.

Evidence is owned at the highest existing seams. Conic qualification enters
through `conic_encounter`, public Surface actions, and independent mathematical
oracles. Source qualification enters through the three public Source calls and
their Assembly/Workstation replay. Private tests are permitted only for a
certification fact that cannot be demonstrated reliably through those seams;
the private file layout itself is not a test contract. State Installation,
Assembly facts, Workstation, propagation preparation, and new optical
capability are out of scope except as no-drift consumers.
