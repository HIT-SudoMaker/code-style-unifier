# Domain docs

ChromatixNext is a single-context repository.

Before exploring or changing the project, engineering skills read the root
`CONTEXT.md` and the relevant decisions under `docs/adr/`. Missing documents do
not block work; `domain-modeling` creates or extends them only when a term or a
durable architectural decision is actually resolved.

Specifications, tickets, tests, and implementation use the canonical terms in
`CONTEXT.md`. Synonyms listed under `_Avoid_` are not used as replacement domain
language. Any proposal that contradicts an existing ADR must identify that
conflict explicitly rather than silently replacing the decision.
