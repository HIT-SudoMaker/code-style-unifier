# Triage labels

| Canonical role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | More information is required. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and agent-ready. |
| `ready-for-human` | `ready-for-human` | Human implementation is required. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

Engineering skills use the local status in the second column whenever they
refer to one of the canonical roles.
