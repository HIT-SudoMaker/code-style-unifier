# Examples

These five executable teaching cases consume the public optical core in one
direction. The minimal path teaches direct scientific composition without an
execution shell. The four system cases accept one preselected Workstation and
report a small serializable summary. Scientific proof remains with Component
tests and each case exposes one independently inspectable observable.

## Index

1. [`minimal_optical_path`](minimal_optical_path/README.md) —
   the eight-concept direct path from grid to detected intensity.
2. [`basic_plane_wave_intensity`](basic_plane_wave_intensity/README.md) —
   transverse polarization and intensity.
3. [`basic_ideal_lens_focusing`](basic_ideal_lens_focusing/README.md) —
   pupil-limited ideal-lens focusing.
4. [`propagation_scalar_angular_spectrum`](propagation_scalar_angular_spectrum/README.md) —
   radiative angular-spectrum propagation to a destination grid.
5. [`analytic_michelson_interferometer`](analytic_michelson_interferometer/README.md)
   — complementary RELATIVE outputs from one ideal Cube encountered on the
   outward and return paths of a finite Michelson interferometer.

Run any case from the repository root with Python 3.12. Every command-line
physical value is an SI value; local constants in the source make displayed
micrometres and millimetres readable.

No Example adds a configuration system, runtime registry, notebook,
benchmark, plotting dependency, or validation framework.
